# Panduan administrator

Gunakan menu Data Pegawai, Data Kantor, Kecamatan & Desa, Jadwal Kerja, Kalender Libur, dan Pengaturan untuk mengelola data sesuai role. Super Admin membuat akun admin melalui Pengaturan; akun pegawai baru dibuat otomatis sebagai role Pegawai saat data pegawai disimpan. Pastikan ID unik, relasi kantor/desa/kecamatan benar, email lowercase, status `ACTIVE`, dan role tepat. Menambah kecamatan/desa/kantor/pegawai memerlukan record pada tab terkait; mengubah koordinat/radius atau jadwal wajib dicatat dan diuji. Admin pertama dibuat secara manual oleh pemilik pada USERS; jangan menyebarkan spreadsheet kepada admin wilayah.

Penugasan dan koreksi membutuhkan alur persetujuan yang harus ditinjau; aplikasi versi ini mendukung sebagian pengajuan/keputusan tugas namun belum UI lengkap maupun keputusan koreksi.
