# Panduan administrator

Pendaftaran awal dan perubahan master saat ini dilakukan terkontrol pada sheet database, sebab UI CRUD lengkap belum tersedia. Pastikan ID unik, relasi kantor/desa/kecamatan benar, email lowercase, status `ACTIVE`, dan role tepat. Menambah kecamatan/desa/kantor/pegawai memerlukan record pada tab terkait; mengubah koordinat/radius atau jadwal wajib dicatat dan diuji. Admin pertama dibuat secara manual oleh pemilik pada USERS; jangan menyebarkan spreadsheet kepada admin wilayah.

Penugasan dan koreksi membutuhkan alur persetujuan yang harus ditinjau; aplikasi versi ini mendukung sebagian pengajuan/keputusan tugas namun belum UI lengkap maupun keputusan koreksi.
