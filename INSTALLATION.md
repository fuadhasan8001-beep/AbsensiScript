# Instalasi dari nol

1. Buat project Google Apps Script V8 dan salin file `.gs`/HTML beserta `appsscript.json` (atau unggah dengan clasp).
2. Buat project Google Cloud yang terkait, aktifkan Apps Script API dan Identity Toolkit API.
3. Buat Firebase project; aktifkan Authentication > Google serta Email/Password dan daftarkan konfigurasi web app. Deploy Apps Script sebagai web app dengan akses publik agar semua pendaftar dapat membuka layar login. Setelah deployment dibuat, buka URL web app dan catat hostname yang tampil/terdeteksi aplikasi. Tambahkan hostname itu di Firebase Console > Authentication > Settings > Authorized domains (hostname saja, tanpa `https://` atau path). Apps Script biasanya memakai `script.google.com` atau `script.googleusercontent.com`; tambahkan hostname deployment yang benar-benar digunakan. Jika memakai domain kustom, tambahkan domain tersebut juga.
4. Tambahkan Script Properties `FIREBASE_WEB_API_KEY`, `FIREBASE_AUTH_DOMAIN`, `FIREBASE_PROJECT_ID`. Database sudah diarahkan ke spreadsheet yang ditentukan di `Config.gs`; bila ingin mengganti target, set Script Property `DATABASE_SPREADSHEET_ID` untuk menimpa default tersebut. API key Firebase web adalah identifier publik, bukan secret; batasi API key pada API/domain yang diperlukan. Token tidak disimpan ke Sheets.
5. Buat spreadsheet database kosong. Jalankan `initializeDatabase()` dari editor Apps Script sebagai pemilik. Berikan akses spreadsheet hanya kepada akun pemilik deployment.
6. Untuk membuat Super Admin pertama, isi Script Property sementara `FIRST_SUPER_ADMIN_EMAIL` dengan email Google admin, simpan, lalu jalankan fungsi `createFirstSuperAdmin()` dari editor Apps Script. Fungsi menolak berjalan bila Super Admin sudah ada dan menghapus property bootstrap setelah berhasil. Email harus sama dengan akun Google Firebase.
7. Pastikan spreadsheet dan Script Properties tidak dibagikan ke pegawai. Uji akun aktif dan akun tak terdaftar sebelum deployment.
8. Tab `REGISTRATION_REQUESTS` dibuat otomatis saat alur pendaftaran pertama digunakan. Pemilik juga dapat menjalankan `initializeDatabase()` untuk menyiapkan seluruh tab lebih awal. Pengguna baru dapat mendaftar dengan username/password atau Google; semua pendaftaran menunggu persetujuan Super Admin yang menetapkan role di halaman Pengaturan. Username/password memakai akun Firebase dengan identitas internal `username@FIREBASE_AUTH_DOMAIN`; alamat email asli tidak diperlukan, sehingga pemulihan password harus dilakukan administrator Firebase.

Firebase API key tidak memberi akses admin sendiri. Server memvalidasi ID token dengan endpoint Google Identity Toolkit sebelum membaca data pengguna.
